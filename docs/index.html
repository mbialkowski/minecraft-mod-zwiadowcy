Nieoficjalny mod fanowski do Minecraft Java 1.20.1 (Forge)

Zwiadowcy: Ruiny Gorlanu

Fabularny mod na motywach „Zwiadowców” Johna Flanagana. Grasz jako Will, który zostaje uczniem zwiadowcy Halta: 14 misji, nowy wymiar Araluen, skradanie się, łuk, koń i bossowie. Wszystko po polsku.

Pobierz moda Instrukcja instalacji

Zrzuty ekranu

Kliknij zdjęcie, żeby je powiększyć. Między zdjęciami przechodzisz strzałkami albo przesuwając palcem.

Nieoficjalny mod fanowski. Fabuła jest wolną interpretacją wydarzeń z „Ruin Gorlanu” Johna Flanagana; świat, postacie i nazwy należą do ich właścicieli. Mod nie jest związany z autorem ani wydawcami serii, jest darmowy i niekomercyjny.
